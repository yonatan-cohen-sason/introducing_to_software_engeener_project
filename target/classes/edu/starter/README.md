# Java Battle Game week 3
## Description
You are a fighter battling against two enemies in two different rounds.
Your goal is to defeat both enemies before they defeat you!
You can attack, defend, use special attacks, recover resources, and choose a reward after winning the first round to help you in the second one.

Theme: Creature 

## Requirements
JDK 25 (LTS)

## How to Compile
Open the terminal in the folder thats contains the edu folder and run this command:
`javac -d . edu\starter\Main.java`

## How to Run
Run this command in the same folder:
`java -cp . edu.starter.Main`

## How to Play
Use keys 1–4 to choose your actions during battles, and keys 1–2 to choose a reward after winning the first battle.
